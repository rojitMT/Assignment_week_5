# React Wordle

A Wordle game clone built using React, JavaScript, HTML, and CSS.

## Features

- 6 × 5 game grid
- Physical and virtual keyboard input
- Word validation
- Color feedback (green, yellow, gray)
- Win and loss detection
- Responsive design

## Technologies Used

- React
- JavaScript (ES6+)
- HTML5
- CSS3
- Vite
